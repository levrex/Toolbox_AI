# Iris Dataset Analysis Skill

## Objective
Provide insights into the Iris dataset by analyzing feature distributions across different flower species (`setosa`, `versicolor`, `virginica`).

## Procedure
1. Load the Iris CSV dataset using the provided python execution tool.
2. Calculate summary metrics (mean, std, min, max) for:
   - Sepal Length
   - Sepal Width
   - Petal Length
   - Petal Width
3. Group analysis by species.
4. Output a clean Markdown table summarizing feature differences.
